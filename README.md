# Безопасность ОС. Лабораторная работа 1

Номер студенческого билета: **М265917**

РЕД ОС 8, стандартная серверная редакция без графической оболочки.

## Настройки

| Пункт | Настройка |
| --- | --- |
| Пользователь | `user1`, UID `1234`, домашняя директория `/home/user1` |
| Группа | `user1` входит в `students` |
| Пароль | Смена каждые 90 дней |
| Мониторинг | set-UID-файлы в `find.out`, процесс `passwd` с RUID `1234` и EUID `0` в `ps.out` |
| set-UID | `/home/user1/cat`, владелец `root`, права `4750`, чтение `/etc/gshadow` |
| Привилегии | `/home/user1/chown` с `cap_chown=ep`, смена владельца файла на `root` |
| sudo | Пользователю `user1` разрешено изменять системное время командой `date -s` |

## Проверка

```sh
id user1
chage -l user1
getcap /home/user1/chown
sudo -l -U user1
```

Настройки проверены после перезагрузки.

В репозитории собраны обязательные файлы из таблицы задания.
